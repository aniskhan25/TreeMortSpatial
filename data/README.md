# Data

The analysis expects `clusters_with_distance.csv` in this directory.

## How to produce it

Run the [TreeClusters](https://github.com/aniskhan25/TreeClusters) pipeline:

```bash
# 1. Cluster dead tree points
python src/clusters.py \
    --data-path data/DeadTrees_2023_Anis_ShapeStudy.gpkg \
    --output-dir output/

# 2. Extract raster patches (HPC — see scripts/run_patches.sh)

# 3. Compute environmental distances
python src/distances.py   # produces output/clusters_with_distance.csv
```

Copy the result here:

```bash
cp /path/to/TreeClusters/output/clusters_with_distance.csv data/
```

## Expected columns

| Column | Description |
|---|---|
| x, y | UTM coordinates (EPSG:3067) |
| cluster_id | DBSCAN label (−1 = noise/isolated) |
| ... | Environmental feature columns from distances.py |

## Sample data

A 1 000-row sample (for testing notebooks without the full dataset) can be
